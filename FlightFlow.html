✈️ AeroDataBox — Live Flight Data

Free at rapidapi.com → AeroDataBox — sign up → Subscribe Basic (free) → copy your RapidAPI key. Works on Codecademy ✅

Which key? After subscribing on RapidAPI, go to your app → "Authorization" → copy the X-RapidAPI-Key value. It looks like: a1b2c3d4e5f6...

Note: For the AeroDataBox API key, use the "Airport departures and arrivals (by time range) / TIER 2" key in the Flight API section.
🌤 OpenWeatherMap — Weather and Air Quality

Free at openweathermap.org — 1,000 calls/day, no CORS issues, works on Codecademy ✅

💬 Community Feedback — optional

Without this, feedback saves only on your device. To make it visible to everyone: free at supabase.com → New project → SQL Editor → paste and run:
create table public.feedback (id bigint generated always as identity primary key, name text, rating int, msg text, created_at timestamptz default now()); alter table public.feedback enable row level security; create policy "public insert" on public.feedback for insert to anon with check (true); create policy "public read" on public.feedback for select to anon using (true);Then Project Settings → API → copy the Project URL and anon public key below.

Add to phone or tablet (no app store needed)
iOS (iPhone/iPad):
1. Open FlightFlow in Safari
2. Tap the Share button (box with arrow)
3. Tap "Add to Home Screen"
4. Name it FlightFlow and tap Add

Android:
1. Open FlightFlow in Chrome
2. Tap the 3-dot menu
3. Tap "Add to Home screen" or "Install app"
4. It installs like a real app!
For real App Store / Google Play
To publish on the App Store or Google Play, you need to wrap this HTML file in a native shell:

• Capacitor (free) — convert any web app to iOS/Android. capacitorjs.com
• Cordova (free) — older but widely supported. cordova.apache.org
• PWABuilder (free) — Microsoft tool to package PWAs. pwabuilder.com

App Store requires Apple Developer account ($99/yr). Google Play is $25 one-time.
